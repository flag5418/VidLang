## 二、核心设计规律总结

### 2.1 有字幕 vs 无字幕 的差异

这是用户强调的关键点:

| 维度 | 有字幕 | 无字幕 |
|------|--------|--------|
| **竖屏-媒体区域** | 视频 + 字幕覆盖层(多行) | 纯视频 / 音频封面 |
| **竖屏-底部栏** | 👁字幕开关 + 播放控制 + ⚙️设置 | 可能无👁按钮 |
| **竖屏-设置面板** | 倍速/循环/字号/定时/注音 | ? |
| **横屏-媒体区域** | 视频 + 浮动当前句字幕条 | 纯视频 |
| **横屏-底部栏** | 翻译+字幕+单句暂停+单句循环+倍速... | 精简版(?少字幕相关) |
| **右侧浮动按钮** | 编辑+跟读+音量 | 可能只有部分 |

### 2.2 竖屏 vs 横屏 差异

| 维度 | 竖屏(Portrait) | 横屏(Landscape) |
|------|----------------|-----------------|
| **TopBar** | 返回 + BETA + 收藏+历史+列表 | 返回 + "BETA 文件名" + 收藏+列表+设置 |
| **媒体区域** | 全宽 + 字幕多行覆盖层 | 左侧 + 右侧浮动按钮组 + 浮动字幕条 |
| **设置入口** | ⚙️按钮 → 展开中间面板 | ⚙️按钮 → 侧边栏"播放设置"Tab |
| **功能按钮** | 设置面板展开后水平排列 | 底部栏一行文字按钮排开 |
| **进度条位置** | 底部控制栏上方 | 底部控制栏内嵌 |
| **侧边栏** | 全屏右侧滑出(覆盖) | 右侧分栏(压缩视频区) |
| **底部栏布局** | 2行(进度条 + 控制按钮) | 1行(全部内联) |

### 2.3 控件层级结构

```
UnifiedPlayerPage (Scaffold)
├── Stack
│   ├── MediaArea (视频/音频 + 字幕)
│   ├── TopBar (顶部导航)
│   ├── RightFloatingButtons (仅横屏: 编辑/跟读/音量)
│   ├── FloatingSubtitleBar (仅横屏有字幕: 当前句)
│   ├── BottomControls (底部控制栏)
│   │   ├── ProgressBar (进度条)
│   │   ├── ControlRow1: [字幕显隐] [|◀] [▶/⏸] [▶|] [⚙️设置]
│   │   └── SettingsPanel (竖屏可展开): [倍速] [循环] [单句循环] [字号] [定时]
│   ├── SideDrawer (侧边栏)
│   │   ├── TabBar: [资源列表] | [播放设置]
│   │   ├── ResourceListContent
│   │   └── SettingsContent
│   │       ├── PlayModeRadio (播放模式)
│   │       ├── TimerCloseSection (定时关闭)
│   │       ├── FontSizeSlider (字号)
│   │       └── AutoPlaySwitch (按下一句自动播放)
│   └── FollowPanelOverlay (跟读面板, 可选覆盖)
└── SafeArea
```
