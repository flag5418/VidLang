# 生词本重设计

## 目标

- 以“认识 / 不认识”两档状态重构生词本主流程。
- 保留现有滑词收藏入口，优先打通收藏、浏览、详情、状态切换、测试复用。
- 详情页先采用轻量方案，展示逻辑尽量复用当前 `WordCardData`。

## 范围

本次仅处理以下内容：

- `WordBook` 数据模型收敛为两档状态。
- 生词本主页改为“分类/标签 + 列表”的主视图。
- 详情页补齐认识、不认识、删除操作。
- 生词测试复用现有单元测试链路，输入源切换为生词本所选单词。

本次暂不处理：

- 翻译弹窗与生词详情完全统一。
- 复杂抽屉式响应布局细节。
- 完整拍照翻译与高级标签管理交互。

## 状态模型

### 主状态

- `learning`: 生词
- `mastered`: 已认识

### 状态流转

- 收藏单词时默认写入 `learning`
- 点击“认识”时切换为 `mastered`
- 已认识点击“不认识”时切回 `learning`
- 已认识点击“删除”时执行软删除

### 辅助字段

以下字段不再参与主状态机，只作为测试与复习辅助信息保留：

- `reviewCount`
- `correctCount`
- `lastReviewAt`
- `nextReviewAt`

`reviewing` 不再作为独立状态使用。

## 数据设计

### `word_book`

保留现有表，重点调整语义：

- `mastery_level` 仅允许 `learning / mastered`
- `definitions_json` 继续缓存释义
- `phonetic_uk / phonetic_us` 继续缓存音标
- `context_sentence / source_title / screenshot_path` 保留用于详情展示

### 标签

新增并启用以下实体：

- `word_tag`
- `word_book_tag`

用途：

- 左侧导航按“状态 + 标签”聚合筛选
- 列表卡片展示标签
- 详情页支持轻量增删标签

## 服务拆分

### `WordBookService`

负责以下能力：

- `saveWord`: 收藏、去重、缓存词典数据
- `queryWords`: 按状态、标签、关键字查询
- `updateMastery`: 认识 / 不认识状态切换
- `softDeleteWord`: 软删除已认识单词

### `WordTagService`

新增服务，负责：

- 标签列表查询
- 单词标签绑定与解绑
- 左侧导航计数聚合

### 测试适配层

新增一层生词本测试适配逻辑，职责只有两件事：

- 根据当前筛选或选择结果输出待测单词集合
- 将单词集合转换为现有综合测试/单元测试可消费的数据输入

不在生词本模块内重写测试引擎。

## 页面设计

### 主页

主页分为三块：

- 顶部：标题、数量、测试按钮、复习按钮
- 左侧：`生词`、`已掌握` 两组及其标签导航
- 右侧：单词列表

首期实现可先在手机上用单列页面表达同一套数据结构，但内部状态按“左导航 + 右列表”组织，便于后续做分栏和 Drawer。

### 列表项

列表卡片显示：

- 单词
- 音标
- 第一条释义
- 来源图标
- 标签
- 复习次数

交互：

- 点击卡片进入详情
- 点击标签进入标签编辑
- 选择模式下支持勾选

### 详情页

详情页先走轻量方案，数据结构尽量贴近 `WordCardData`：

- 单词
- 音标
- 释义
- 例句
- 来源上下文
- 标签
- 学习记录摘要

底部主操作：

- `不认识`
- `认识`

附加操作：

- 已认识状态允许软删除

## 数据流

### 收藏

1. 用户在滑词弹窗点击收藏
2. `WordBookService.saveWord` 执行去重
3. 写入 `word_book`
4. 默认状态为 `learning`
5. 返回结果给弹窗更新“已收藏”

### 浏览

1. 页面根据当前状态、标签、关键字生成查询条件
2. 服务层返回单词列表与分组计数
3. 页面渲染左侧导航和右侧列表

### 状态切换

1. 用户在详情或复习页点击“认识 / 不认识”
2. 服务层更新 `mastery_level`
3. 同步更新 `reviewCount / correctCount / lastReviewAt`
4. 页面刷新当前列表和计数

### 删除

1. 仅 `mastered` 状态允许删除
2. 执行软删除
3. 导航计数与列表即时刷新

## 错误处理

- 收藏重复时直接返回已存在记录，不视为错误
- 标签关联失败时不影响主单词记录
- 截图缺失时详情页降级展示文本信息
- 释义缓存缺失时详情页允许只展示单词、来源、上下文

## 实现顺序

1. 收敛 `WordBook` 状态模型
2. 注册并补齐 `WordTag`、`WordBookTag`
3. 重写 `WordBookService` 查询与状态更新接口
4. 重构生词本主页
5. 补轻量详情页与状态操作
6. 接入生词本测试入口

## 风险

- 现有 `word_book` 已使用三态语义，迁移时需要兼容旧数据中的 `reviewing`
- 当前数据库版本固定为 1，新增实体和字段需要依赖现有自动建表/补字段机制
- 测试链路如果强依赖视频字幕输入，需要补一个“生词来源适配器”

## 验收标准

- 生词本只以 `learning / mastered` 两档运行
- 生词与已掌握可双向切换
- 已掌握支持软删除
- 列表可按状态与标签查看
- 详情页可完成核心查看与状态切换
- 生词测试可复用现有测试链路启动
