## 三、文档维护规范

### 3.1 更新责任

| 文档类型 | 维护者 | 更新频率 |
|----------|--------|----------|
| 项目全局规则 | Tech Lead | 重大变更时 |
| AGENT_CONTEXT.md | 全体开发者 | 每次功能变更后 |
| 代码知识库 | Feature Owner | 新模块开发完成后 |
| 设计文档 | Designer + PM | 设计评审通过后 |
| API 文档 | Backend Developer | 接口变更时 |

### 3.2 版本管理

- 设计文档使用版本号：`文档名-V{版本}.md`
- 代码知识库文档在文件头标注版本和日期
- 修改前备份旧版本到 `developer/archive/`

### 3.3 文档一致性检查

**每月例行检查项：**
- [ ] 技术栈描述是否与 `pubspec.yaml` 一致
- [ ] 数据库表结构是否与代码一致
- [ ] 目录结构描述是否与实际一致
- [ ] API 接口文档是否与最新代码一致
- [ ] 已知问题列表是否已修复或更新

> 📋 **完整维护清单**: 请参考 [`MAINTENANCE_CHECKLIST.md`](developer/MAINTENANCE_CHECKLIST.md)
