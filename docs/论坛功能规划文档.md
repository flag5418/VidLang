# 论坛功能规划文档

> 版本：v1.0  
> 更新日期：2026-07-22  
> 状态：定稿

## 一、论坛定位与核心原则

### 1.1 定位

一个面向**英语学习社群**的轻量级交流论坛，核心价值在于提供简单、高效的信息发布与浏览体验。

### 1.2 核心原则

| 原则 | 说明 |
|------|------|
| **英语学习社群** | 论坛围绕英语学习主题，内容方向聚焦资源分享、经验交流、学习打卡、求助答疑等 |
| **轻量交流场** | 不做重型功能（如嵌套回复、富文本编辑器、复杂权限体系），保持交互简洁 |
| **发布即见** | 帖子发布后立即对所有人可见，无需审核，降低发布摩擦 |
| **标签组织** | 帖子按标签归类，用户可浏览全部帖子或按标签筛选；支持屏蔽不感兴趣的标签 |


## 三、核心功能清单

### 3.1 用户端功能

#### 3.1.1 浏览信息流

- 默认展示全部帖子，按发布时间倒序
- 顶部标签导航栏，支持按单个标签筛选
- 支持"只看关注人"模式
- 列表卡片展示：标题（截取前N字）、作者头像+昵称、发布时间、标签、点赞数、评论数
- 分页加载，每页 20 条

#### 3.1.2 发布帖子

- 文本内容：纯文本，限制 1-5000 字
- 资源链接：可选，一个 URL 字段
- 标签：必选，从 6 个主标签中单选
- 配图：可选，最多 1 张，仅支持 jpg/png/webp
- 发布流程：客户端本地压缩图片 → 上传至 Supabase Storage → 写入帖子记录
- 发布后立即出现在信息流中

#### 3.1.3 帖子详情

- 展示帖子完整内容、配图、标签、作者信息、发布时间
- 展示点赞数、收藏数、评论数
- 底部操作栏：点赞、收藏、评论入口

#### 3.1.4 评论

- 评论为单层结构，不支持回复评论（即不支持评论的评论）
- 评论内容：纯文本，限制 1-500 字
- 按发布时间正序排列
- 支持点赞评论

#### 3.1.5 点赞

- 支持点赞帖子
- 支持点赞评论
- 同一用户对同一对象只能点赞一次，再次点击取消点赞
- 点赞数实时更新

#### 3.1.6 收藏

- 用户可收藏帖子
- 在我的页面"我的收藏"中查看
- 支持取消收藏

#### 3.1.7 关注用户

- 关注其他用户后，可在"关注人动态"中查看其发布的新帖
- 支持取消关注

#### 3.1.8 举报

- 用户可举报帖子或评论
- 举报需选择原因（色情低俗/垃圾广告/辱骂攻击/其他）
- 举报提交后进入管理后台待处理队列

#### 3.1.9 屏蔽标签

- 用户可在设置中屏蔽指定标签
- 被屏蔽标签的帖子不出现在该用户的信息流中
- 存储在 user_tag_preferences 表

### 3.2 我的页面子模块

| 子模块 | 功能说明 |
|--------|----------|
| 论坛入口 | 查看我发布的帖子列表 |
| 软件反馈 | 提交对 App 的反馈建议，查看反馈历史及管理员回复 |
| 我的收藏 | 查看收藏的帖子列表，支持取消收藏 |
| 我的关注 | 查看关注的用户列表，支持取消关注 |
| 互动消息 | 被点赞的帖子、我点赞的帖子、关注人新帖动态 |
| 私信/通知 | 系统通知（下架通知、禁言通知等），查看后标记已读 |
| 管理后台 | 仅管理员角色可见，进入后台管理页面 |

### 3.3 管理员后台功能

| 功能 | 说明 |
|------|------|
| 帖子下架 | 管理员可下架违规帖子，下架后帖子不在信息流中展示，帖子作者收到系统通知 |
| 帖子置顶 | 管理员可置顶帖子，置顶不限数量，置顶帖始终排在信息流最前 |
| 举报处理 | 查看举报列表，对举报内容执行下架/忽略操作 |
| 用户禁言 | 管理员可对违规用户设置禁言期限（1天/3天/7天/30天/永久），禁言期间不可发布帖子和评论，用户收到系统通知 |
| 回复反馈 | 管理员对用户提交的软件反馈进行回复 |

## 四、数据库表设计

### 4.1 forum_posts（帖子表）

```sql
CREATE TABLE forum_posts (
    id            BIGSERIAL PRIMARY KEY,
    user_id       UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
    title         TEXT NOT NULL,
    content       TEXT NOT NULL,
    tag           TEXT NOT NULL CHECK (tag IN ('资源', '求助', '经验', '打卡', '交友', '闲聊')),
    resource_url  TEXT,
    image_url     TEXT,
    is_pinned     BOOLEAN DEFAULT FALSE,
    is_removed    BOOLEAN DEFAULT FALSE,
    removed_reason TEXT,
    removed_by    UUID REFERENCES auth.users(id),
    removed_at    TIMESTAMPTZ,
    like_count    INTEGER DEFAULT 0,
    comment_count INTEGER DEFAULT 0,
    favorite_count INTEGER DEFAULT 0,
    created_at    TIMESTAMPTZ DEFAULT NOW(),
    updated_at    TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_forum_posts_user_id ON forum_posts(user_id);
CREATE INDEX idx_forum_posts_tag ON forum_posts(tag);
CREATE INDEX idx_forum_posts_created_at ON forum_posts(created_at DESC);
CREATE INDEX idx_forum_posts_is_removed ON forum_posts(is_removed);

-- RLS 策略
ALTER TABLE forum_posts ENABLE ROW LEVEL SECURITY;

-- 所有人可读未下架帖子
CREATE POLICY "Anyone can read non-removed posts"
ON forum_posts FOR SELECT
USING (is_removed = FALSE);

-- 作者可读自己的全部帖子（含已下架）
CREATE POLICY "Authors can read own posts"
ON forum_posts FOR SELECT
USING (auth.uid() = user_id);

-- 管理员可读所有帖子
CREATE POLICY "Admins can read all posts"
ON forum_posts FOR SELECT
USING (EXISTS (
    SELECT 1 FROM user_roles WHERE user_id = auth.uid() AND role = 'admin'
));

-- 登录用户可创建帖子
CREATE POLICY "Authenticated users can create posts"
ON forum_posts FOR INSERT
WITH CHECK (auth.uid() = user_id);

-- 作者可编辑自己的帖子（未下架）
CREATE POLICY "Authors can update own posts"
ON forum_posts FOR UPDATE
USING (auth.uid() = user_id AND is_removed = FALSE);

-- 管理员可更新帖子（用于下架/置顶）
CREATE POLICY "Admins can update posts"
ON forum_posts FOR UPDATE
USING (EXISTS (
    SELECT 1 FROM user_roles WHERE user_id = auth.uid() AND role = 'admin'
));

-- 管理员可删除帖子
CREATE POLICY "Admins can delete posts"
ON forum_posts FOR DELETE
USING (EXISTS (
    SELECT 1 FROM user_roles WHERE user_id = auth.uid() AND role = 'admin'
));
```

## 五、接口设计

所有接口统一通过 **Supabase Edge Functions** 实现，数据库直连操作走 Supabase Client SDK + RLS。

### 5.1 Edge Functions 清单

| Function 名称 | 方法 | 功能 | 说明 |
|---------------|------|------|------|
| `forum-create-post` | POST | 创建帖子 | 校验内容、标签，写入帖子表，触发通知 |
| `forum-list-posts` | GET | 帖子列表 | 支持分页、标签筛选、排除屏蔽标签、置顶优先 |
| `forum-post-detail` | GET | 帖子详情 | 返回帖子 + 前 N 条评论 |
| `forum-create-comment` | POST | 创建评论 | 校验内容长度，更新帖子评论计数 |
| `forum-toggle-like` | POST | 点赞/取消点赞 | 原子操作，更新计数 |
| `forum-toggle-favorite` | POST | 收藏/取消收藏 | 原子操作，更新计数 |
| `forum-toggle-follow` | POST | 关注/取消关注 | 校验不关注自己 |
| `forum-report` | POST | 提交举报 | 写入举报表 |
| `forum-admin-remove-post` | POST | 下架帖子 | 管理员权限校验，发送通知 |
| `forum-admin-pin-post` | POST | 置顶/取消置顶 | 管理员权限校验 |
| `forum-admin-handle-report` | POST | 处理举报 | 下架内容或标记忽略 |
| `forum-admin-mute-user` | POST | 禁言用户 | 设置禁言期限，发送通知 |
| `forum-admin-reply-feedback` | POST | 回复反馈 | 管理员回复用户反馈 |
| `forum-my-posts` | GET | 我的帖子 | 当前用户发布的帖子 |
| `forum-my-favorites` | GET | 我的收藏 | 当前用户收藏的帖子 |
| `forum-my-following` | GET | 关注列表 | 当前用户关注的用户 |
| `forum-following-dynamics` | GET | 关注人动态 | 关注用户近期发布的帖子 |
| `forum-notifications` | GET | 通知列表 | 当前用户的系统通知 |
| `forum-mark-notification-read` | POST | 标记已读 | 标记单条或全部通知已读 |
