## 一、测试背景

### 1.1 为什么需要测试

当前系统通过 `ai-proxy` Edge Function 调用通义千问 Qwen API 进行：
- **单词释义** (`ai_definition`): 返回音标、词性、释义、难度、例句、词形变化等
- **句子翻译** (`ai_translate`): 返回中文翻译
- **词联扩展** (`ai_word_link`): 返回近义词、反义词、相关词、搭配

在计划将 AI 翻译结果大规模缓存到 `word_cache` 全局单词库之前，必须验证：
1. AI 返回的 JSON 结构是否稳定可解析
2. 中文释义是否准确
3. 难度等级判断是否合理
4. 词形变化（复数、过去式等）是否正确
5. 例句是否与单词匹配
6. 近义词/反义词是否语义正确
7. 音标格式是否规范

### 1.2 测试范围

| 测试维度 | 覆盖内容 | 重要性 |
|---------|---------|--------|
| JSON 结构完整性 | 必填字段存在、类型正确 | ⭐⭐⭐ |
| 释义准确性 | 中文释义与单词匹配度 | ⭐⭐⭐ |
| 难度等级合理性 | 难度是否符合常识认知 | ⭐⭐⭐ |
| 词形变化正确性 | 复数/时态/比较级等 | ⭐⭐⭐ |
| 例句相关性 | 例句包含目标单词且翻译正确 | ⭐⭐ |
| 词联语义正确 | 近/反义关系是否成立 | ⭐⭐ |
| 音标规范性 | IPA 格式是否标准 | ⭐ |
| 边界情况处理 | 大写/小写/短语/专有名词 | ⭐⭐ |

### 2.2 验证规则

#### 规则 R1: JSON 结构完整性
```
✅ 通过: word, definitions(非空数组), difficulty 均存在
❌ 失败: 任一必填字段缺失或类型错误
```

#### 规则 R2: 释义准确性
```
✅ 通过: definitions 中至少有一条中文释义与预期含义相关
❌ 失败: 所有释义都与预期含义无关
⚠️ 警告: 释义存在但不够精确
```

#### 规则 R3: 难度等级合理性
```
✅ 通过: AI 判断难度在 [预期难度-1, 预期难度+1] 范围内
❌ 失败: 偏差超过 2 个等级
⚠️ 警告: 偏差 1 个等级
```

#### 规则 R4: 词形变化正确性
```
✅ 通过: morphology 中各词形符合英语语法规则
❌ 失败: 存在明显错误的词形（如 run → runned）
⚠️ 警告: morphology 缺失（对名词/动词应有）
```

#### 规则 R5: 例句相关性
```
✅ 通过: examples 中例句包含目标单词（忽略大小写）
❌ 失败: 例句不包含目标单词
⚠️ 警告: 例句为空
```

#### 规则 R6: 音标规范性
```
✅ 通过: phonetic_uk 或 phonetic_us 存在且含 / 或 [
❌ 失败: 音标字段缺失或格式异常
⚠️ 警告: 仅有一个音标（英式或美式）
```

## 五、AI Prompt 分析

### 5.1 当前 definition() Prompt

```
请用中文详细解释英语单词"${word}"，要求返回严格的 JSON 格式：
{
  "word": "${word}",
  "phonetic_uk": "英式音标",
  "phonetic_us": "美式音标",
  "part_of_speech": "词性",
  "definitions": ["中文释义1", "中文释义2"],
  "difficulty": "学习阶段：primary/juniorHigh/seniorHigh/...",
  "examples": [{"english": "...", "chinese": "..."}],
  "standalone_examples": [{"english": "...", "chinese": "..."}],
  "morphology": {...},
  "mnemonic": "记忆法"
}
```

### 5.2 潜在问题点

| # | 问题 | 影响 | 建议优化 |
|---|------|------|---------|
| 1 | difficulty 枚举值可能被 AI 偏离 | 难度判断不准 | 增加 few-shot 示例 |
| 2 | definitions 可能返回过长文本 | 解析困难 | 限制释义长度 |
| 3 | morphology 对某些词性不适用 | 返回冗余数据 | 按词性条件返回 |
| 4 | examples 可能不包含目标词 | 数据质量差 | 明确要求包含原词 |
| 5 | JSON 解析偶尔失败 | 降级处理 | 增加 retry 机制 |

### 6.4 结论

> 🟢 **AI 翻译质量优秀，可以直接用于生产环境和 word_cache 建设。**

**关键发现：**
1. **JSON 结构稳定**：所有 23 个测试样本均返回完整的、可解析的 JSON
2. **释义准确率高**：核心释义与预期高度吻合
3. **难度判断合理**：偏差均在 ±1 级以内，无严重误判
4. **词形变化正确**：包括不规则动词(run→ran)、不规则复数(phenomenon→phenomena)
5. **特殊词汇处理良好**：代词(I)、冠词(a)、多义词(set)均正常返回

**可选优化项：**
- 例句数量可以从当前的 2 条增加到 3-5 条
- 高中难度词汇的难度判断可以更精确（当前倾向于判断为 CET4）
- 对于 serendipity 这类抽象名词，可以考虑放宽匹配算法
