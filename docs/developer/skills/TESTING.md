## 验证步骤

1. 打开 opencode 对话
2. 输入测试用例
3. 观察是否加载了对应的 Skill
4. 检查 Skill 工作流是否正确执行
5. 验证检查清单是否提供

## 常见问题

### Q1: Skill 没有触发

**可能原因**：
- opencode.json 配置文件不存在或格式错误
- 触发关键词不匹配
- Skill 文件路径错误

**解决方法**：
1. 检查 opencode.json 是否存在且格式正确
2. 检查触发关键词是否匹配
3. 检查 Skill 文件路径是否正确

### Q2: Skill 加载了但工作流没有执行

**可能原因**：
- Skill 文件格式错误
- 工作流步骤不完整

**解决方法**：
1. 检查 Skill 文件格式
2. 确保工作流步骤完整

### Q3: 检查清单没有提供

**可能原因**：
- Skill 文件中没有定义检查清单
- 检查清单格式错误

**解决方法**：
1. 检查 Skill 文件中的检查清单定义
2. 确保检查清单格式正确
