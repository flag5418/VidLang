## 七、风险与建议

### 7.1 主要风险

| 风险 | 影响 | 应对策略 |
|------|------|----------|
| 竞品 (Duolingo) | 用户获取成本高 | 差异化定位 (视频学习) |
| 付费转化低 | 收入不达预期 | 优化免费/付费功能边界 |
| 合规成本 | 各地区法律要求 | 优先简单市场 |
| AI 成本 | API 调用费用 | 本地模型 + 缓存优化 |

### 7.2 核心建议

```
┌─────────────────────────────────────────────────────────────────┐
│                    核心建议                                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 先做好中国 + 美国                                          │
│     └─ 验证商业模式，不急于全球化                               │
│                                                                 │
│  2. i18n 最小化投入                                            │
│     └─ Phase 1 只需中+英，2-3 周可完成                         │
│                                                                 │
│  3. 差异化定位                                                  │
│     └─ "通过看视频学英语"，而非"游戏化学英语"                  │
│                                                                 │
│  4. 保留现有充值模式                                            │
│     └─ 增加订阅选项，但不强制                                   │
│                                                                 │
│  5. 合规优先级                                                  │
│     └─ 先满足中国 (ICP) + 美国 (隐私) 要求                     │
│                                                                 │
│  6. n18 暂缓                                                    │
│     └─ 教育类应用 4+ 分级足够，无需 18+                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
