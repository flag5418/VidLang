> **状态**: 当前有效

## 一、设计理念变更（V2.0）

### 1.1 核心设计转变

**V1.0 → V2.0 的重大重构**：

| 维度 | V1.0（旧方案） | V2.0（新方案） |
|------|---------------|---------------|
| **复习操作** | 右下角 FAB "复习"按钮 → 进入选择模式 | 点击单词进入详情页 → 底部"认识/不认识"按钮 |
| **测试操作** | 选择模式勾选单词 → 开始测试 | 全局"测试篮"（购物车模式） |
| **选择模式** | 特殊的编辑状态，需要进入/退出 | 常驻 checkbox，无需切换模式 |
| **智能筛选** | 需复习 / 从未测试 / 错误率高 | **暂时移除**（等 SRS 算法就绪后恢复） |

### 1.2 购物车式测试系统

核心类比：**测试 = 购物，测试篮 = 购物车**

```
添加单词到测试篮的入口：
  ① 单词详情页顶部 "[+ 加入测试]" 按钮
  ② 列表常驻 checkbox 勾选 + 底部"加入测试篮"
  ③ 测试篮弹窗内双栏批量选择

执行测试的唯一出口：
  → 测试篮有内容：底部栏 / 悬浮按钮 "开始测试"
  → 测试篮为空：弹出双栏选择弹窗引导添加
```

## 三、导航面板设计

### 3.1 结构

```
┌──────────────────┐
│ ┌──────────────┐ │
│ │ [生词] [已掌握]│ │  ← 一级导航：Segmented Control 风格
│ └──────────────┘ │
│                  │
│ 标签分组          │  ← 二级导航
│ ● 全部       1   │  ← 选中态：主题色圆点 + 加粗
│ ○ ●212       1   │  ← 未选中：空心圆
│ ○ CET4       5   │
│ ○ 高中        3   │
│ ○ 考研        2   │
└──────────────────┘
```

### 3.2 导航规则

- **标签文字**最多显示 6 个字符，超出省略号
- 每个标签右侧显示数量 Badge
- 点击标签筛选右侧列表
- **切换一级导航（生词↔已掌握）时**：默认选中"全部"，刷新列表
- **切换 Tab（单词↔短语）时**：刷新对应类型的导航数据和列表

### 3.3 V2.0 移除内容

- ❌ ~~智能筛选区域~~（需复习 / 从未测试 / 错误率高）
  - 原因：`nextReviewAt` 无算法填充，`reviewCount` 数据不足以支撑有效筛选
  - 计划：等间隔重复（SRS）算法实现后恢复

## 四、单词卡片与交互

### 4.1 卡片布局

```
┌─────────────────────────────────────────────┐
│ ☐  one                        [⋮]  🛒      │  ← checkbox + 单词 + 操作 + 测试篮状态
│ /wʌn/  pron. 一、某个、某一               │  ← 音标 + 词性 + 简要释义
│ [CET4] [高频]                              │  ← 标签 chips
└─────────────────────────────────────────────┘
```

### 4.2 卡片元素说明

| 元素 | 始终显示 | 条件显示 | 交互 |
|------|---------|---------|------|
| **Checkbox** (`☐`/`☑`) | ✅ 是 | — | 点击勾选/取消（加入当前多选集合） |
| **单词文本** | ✅ 是 | — | 点击进入详情页 |
| **操作按钮** `[⋮]` | ✅ 是 | — | 展开更多操作菜单 |
| **测试篮图标** `🛒` | — | 该单词在测试篮中时 | 暗示已添加，点击可移除 |
| **标签 Chips** | ✅ 是 | 有标签时 | 点击管理该单词标签 |

### 4.3 Checkbox 视觉规范

| 状态 | 图标 | 颜色 |
|------|------|------|
| 未选中 | `○` 空心圆（半径 8dp） | `onSurfaceVariant` |
| 已选中 | `●` 实心圆 + 主题色填充 | `primary` |
| 禁用 | `○` 空心圆 | `outlineVariant` (30% opacity) |

**注意**：不使用 Material 的 `checkBoxOutlineBlank` / `checkBox` 图标，改用更简洁的圆形设计。

## 五、单词详情页（复习操作入口）

### 5.1 设计理念

**复习 = 即时的认识/不认识判断**，发生在查看单词详情时。

### 5.2 布局

```
┌──────────────────────────────────────────────┐
│ ← 返回                   [+ 加入测试]        │  ← 顶部：返回 + 加入测试按钮
├──────────────────────────────────────────────┤
│                                              │
│              ┌──────────────┐                │
│              │              │                │
│              │     one      │                │  ← 可点击翻转的区域
│              │   /wʌn/     │                │
│              │              │                │
│              └──────────────┘                │
│            [ 点击翻转查看详情 ]               │
│                                              │
├──────────────────────────────────────────────┤  ← 分隔线以上：翻转区域
│  释义: pron. 一、某个、某一或某一物；         │  ← 分隔线以下：固定显示
│  例句: I have one apple.                     │
│  来源: 视频学习 - Unit 2                     │
│  测试次数: 3 次 · 正确率: 67%               │
│  上次复习: 2026-07-25                        │
│  标签: [CET4] [高频] [+ 添加]               │
├──────────────────────────────────────────────┤
│         [✅ 认识]          [❌ 不认识]        │  ← 底部固定按钮（始终可见）
└──────────────────────────────────────────────┘
```

### 5.3 翻转交互

| 状态 | 正面 | 背面 |
|------|------|------|
| **默认** | 单词 + 音标 | 释义 + 例句 + 学习记录 |
| **点击后** | 3D 翻转动画 (300ms) | 显示背面内容 |
| **再次点击** | 翻转回正面 | — |

### 5.4 底部按钮操作

| 按钮 | 操作 | 后续效果 |
|------|------|---------|
| **✅ 认识** | `masteryLevel = 'mastered'` | Toast "已标记为认识" + 关闭详情 + 刷新列表 |
| **❌ 不认识** | 保持 `masteryLevel = 'learning'` | Toast "继续加油" + 关闭详情 |
| **[+ 加入测试]** | 将单词加入全局测试篮 | 按钮变为 "✓ 已加入 (n)" 或显示 Badge |

### 5.5 Toast 反馈样式

```
✅ 已标记为「认识」，移至已掌握          [撤销]
❌ 标记为「不认识」，继续加油！          [撤销]
🛒 已加入测试篮                          [撤销]
```

## 八、两档记忆评估体系（保留）

### 8.1 核心规则

| 操作 | 效果 |
|------|------|
| 详情页点击「认识」 | 单词从「生词」移入「已掌握」，设置 `masteredAt` 时间 |
| 详情页点击「不认识」 | 单词保留在「生词」中 |
| 已掌握词详情页点「不认识」 | 单词从「已掌握」移回「生词」 |
| 已掌握词删除 | 软删除，不再显示 |

### 8.2 masteryLevel 状态流转

```
收藏单词 → masteryLevel = 'learning'（生词）
详情页点击认识 → masteryLevel = 'mastered'（已掌握）
已掌握点击不认识 → masteryLevel = 'learning'（回到生词）
已掌握点击删除 → isDeleted = true（软删除）
```

### 8.3 复习次数统计（由 TestPage 记录）

- 单词参与一次测试 → `reviewCount += 1`
- 同一场测试同一单词只累计一次
- 答对 → `correctCount += 1`
- 测试完成 → 更新 `lastReviewAt`
