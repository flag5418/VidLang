## 二、打字对英语学习的学术依据

### 2.1 双编码理论（Dual Coding Theory）

Paivio的双编码理论指出：对同一内容以**多种形式编码**，学习效果优于单一形式。打字同时涉及：
- **视觉编码**：看单词/句子
- **动觉编码**：手指击键的肌肉记忆
- **听觉编码**：听发音（配合TTS播放）

这比单纯的"看+读"多了动觉通道，理论上记忆效果更好。

### 2.2 打字与L2学习的实证研究

- McDonald & Foss（2007, 2009）：显式打字训练能**提升L2写作流利度**，参与者对打字训练持积极态度
- Andrä et al.（2020）：动作/手势辅助词汇学习，效果持续**长达6个月**
- 研究表明：打字过程中拼写-手指运动的动作记忆，能强化单词的正字法表征（orthographic representation）

### 2.3 打字在语言学习中的三重价值

| 维度 | 价值 |
|------|------|
| **认知层面** | 多感官编码强化记忆；打字迫使逐字母处理，加深拼写印象 |
| **技能层面** | 提升英文输入速度，为写作/考试/工作打下基础 |
| **情感层面** | 打字练习有"心流"特性，比被动阅读更具参与感 |

## 五、风险与注意事项

### 5.1 风险

| 风险 | 等级 | 说明 |
|------|:---:|------|
| 市场需求验证不足 | 中 | 用户是否愿意在英语APP里练打字，需MVP验证 |
| Web打字体验 | 中 | Flutter内嵌WebView的打字体验（键盘事件、延迟）需要细致打磨 |
| 开发成本 | 中 | 打字模块不是简单功能，需完整的键盘布局、速度统计、错误分析 |
| 移动端打字体验 | 高 | 手机屏幕打字训练体验差，需引导用户在电脑端使用 |

### 5.2 建议

1. **先做电脑端MVP**：用Supabase Edge Function渲染Web打字页面，在macOS/Windows上体验最好
2. **先接入视频字幕**：这是最独特的素材来源，也是用户量最大的引擎
3. **先不做独立计费**：初期作为premium会员的附加功能，观察数据后再决定是否独立计费
4. **打字模式分层**：
   - 初级：看单词打字（拼写训练）
   - 中级：听发音打字（听写训练）
   - 高级：视频字幕盲打（综合训练，看完一段后凭记忆打出）
