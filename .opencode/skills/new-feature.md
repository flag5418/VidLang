# Skill: 实现新功能

> **版本**: V1.0 | **日期**: 2026-07-12
> **触发条件**: 当用户要求实现新功能时

---

## 一、工作流

### 1.1 规划阶段

- [ ] 1. 理解用户需求，明确功能目标
- [ ] 2. 查阅相关功能规范（spec.yaml）
- [ ] 3. 查阅相关知识库文档
- [ ] 4. 设计技术方案
- [ ] 5. 制定实施计划

### 1.2 实现阶段

- [ ] 1. 实现数据模型（如需要）
- [ ] 2. 实现服务层（如需要）
- [ ] 3. 实现状态管理（如需要）
- [ ] 4. 实现页面和组件
- [ ] 5. 实现业务逻辑
- [ ] 6. 更新文档

### 1.3 验证阶段

- [ ] 1. 运行测试
- [ ] 2. 检查代码规范
- [ ] 3. 验证功能完整性
- [ ] 4. 更新知识库
- [ ] 5. 提交代码

---

## 二、检查清单

### 2.1 功能规范

- [ ] 阅读功能规范文档
- [ ] 理解用户故事
- [ ] 理解验收标准
- [ ] 识别技术约束

### 2.2 数据模型

- [ ] 模型符合规范
- [ ] 字段命名正确
- [ ] 关系定义正确
- [ ] 索引设计合理

### 2.3 服务层

- [ ] 服务职责单一
- [ ] 异步方法处理异常
- [ ] 数据库操作安全
- [ ] 文件操作有权限检查

### 2.4 状态管理

- [ ] State 定义完整
- [ ] Notifier 实现完整
- [ ] Provider 定义正确
- [ ] 状态更新逻辑正确

### 2.5 页面

- [ ] 页面结构清晰
- [ ] 组件复用合理
- [ ] 主题适配正确
- [ ] 交互体验良好

### 2.6 文档

- [ ] 更新功能规范
- [ ] 更新知识库
- [ ] 提交 Commit

## 五、注意事项

1. **遵循规范**：所有代码必须遵循项目规范
2. **功能完整**：必须实现所有验收标准
3. **文档完整**：所有代码必须有完整注释
4. **测试覆盖**：核心功能必须有测试
5. **知识库同步**：代码变更必须同步更新知识库
