# CatPaw Commands for VidLang

This directory contains custom CatPaw AI commands for the VidLang project.

## Available Commands

| Command | Description |
|---------|-------------|
| `project-rules` | Load project rules from AGENTS.md |
| `new-module` | Create a new module following conventions |
| `cp` | Copy utility |
| `mv` | Move utility |

## Convention

All project specifications are maintained in `AGENTS.md` at the project root.
CatPaw commands here are shortcuts to reference those specifications.
